Кейси

Вибрані production-проєкти

Retail ops → автоматизація

1С Накладні Звіти Акції

Бекграунд: довго працював оператором комп’ютерного набору — фізичний прийом товару, прихід, розцінка, звіти, аналіз акцій, прорахунок чеків під розіграші, організація свят у магазинах.

Зараз: керую операційним контуром і будую під нього IT (накладні/EDIN, боти замовлень, звіти, акції Happy Day, SMS/Viber) — один контур від полиці до системи.

Production AI: асистент + OCR / документи

OpenAI Function calling OCR FastAPI React

Задача: AI у бізнесі має відповідати й дістати дані лише з реальних API / документів — без галюцинацій цін, наявності чи сум.

Зробив:

- Telegram-асистент → OpenAI → function calling / tools → зовнішні API та база знань; відповідь лише на перевірених даних.

- invoice-agent: LLM + OCR/vision → структуровані поля з накладних/рахунків → контур під 1С (FastAPI + React + Docker).

- Промпти, KB, обробка помилок API, деплой на VPS — як звичайний production-сервіс, не демо-чат.

Telegram-боти + замовлення / retail ops

Python FastAPI PostgreSQL Docker

Задача: прийняти замовлення з поля, сповістити власника, звіти й обмін з 1С без ручного Excel-хаосу.

Зробив: покрокові боти, веб-адмінка (маршрути, точки, товари), звіти HTML/CSV/XLSX/PDF, XML для 1С, інтеграції Nextcloud/CalDAV, моніторинг пошти та цін.

Payroll & HR ERP

Node.js Express Prisma PostgreSQL

Задача: зарплата, табель, KPI й коригування в одній системі замість розрізнених таблиць.

Зробив: full-stack ERP (~80 точок мережі): працівники, розклад, розрахунок ЗП, KPI, перегляди й деталі нарахувань.

Loyalty Admin

React FastAPI 1С

Задача: контроль чеків і балів лояльності з інтеграцією облікової системи.

Зробив: адмін-панель: моніторинг чеків, категорії, зв’язок з 1С.

SMS / Viber розсилки для retail

TurboSMS SMS Viber Sender ID

Задача: офіційні канали сповіщень мережі — не «з сірого номера», а узгоджений відправник під бренд.

Зробив: подав і провів реєстрацію офіційного SMS-відправника та окремо офіційного Viber-відправника для retail-мережі; налаштував і проводив розсилки через TurboSMS — альфа-імена / sender ID, шаблони, робочі кампанії.

BI + хмара + корпоративний сайт

Metabase Nextcloud PHP Hetzner

Задача: аналітика продажів/залишків, файловий контур команди й публічний сайт мережі.

Зробив: ETL → PostgreSQL → Metabase/PostgREST; Nextcloud + OnlyOffice; сайт з локатором магазинів (Maps) і CMS. Деплой і моніторинг на VPS.

Polymarket BTC Sniper (5m)

Python CLOB API paper-first Docker

Задача: низьколатентний sniper для BTC 5m Up/Down на Polymarket — спочатку paper, live лише після жорстких метрик готовності.

Зробив: окремий engine (`scalper`): стратегія й сигнали, paper ledger, live-gate (кількість угод / WR / t-stat / PnL), headless 24/7 на Hetzner, dashboard `/sniper`, CI-тести, безпечний режим без live за замовчуванням.

Polymarket copy-trading

Python FastAPI SQLite risk limits

Задача: дзеркало угод лідерів з ризик-лімітами й аналітикою — інженерний контур, а не «купи все підряд».

Зробив: watcher engine, discover/score лідерів, dashboard, auto-exit / scale-in, health-check, kill-switch, деплой Docker/systemd на VPS; спільний core з sniper (CLOB, HTTP, config).
